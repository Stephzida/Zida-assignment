Differences Between Git Diff AND Git Status
Git status
  • Shows repository status :
    Displays a summary of changes , including :
    • Staged files (added to the index)
    • Unstaged files (modified but not added )
    • Untracked files (new file not added to Git)
  • High-level overview :
    Provides a concise view of the repository's state.
Git diff
  • Shows detailed changes :
    Displays the actual differences between :
    • Working directory and index (unstaged changes): git diff
    • Index and last commit (staged changes) : git diff --cached or git diff --staged .
    • Working directory and last commit : git diff HEAD
  • Line-by-line differences :
    Shows the specific changes made to each file.
Differences Between Git push origin main AND Git push origin -u main
Git push origin main
  • Pushes changes :
    Sends local commits to the remote repository ( origin )on the main branch .
  • No tracking setup :
    Doesn't set up tracking information for the branch .
Git push origin -u main
  • Pushes changes :
    Sends local commits to the remote repository (origin) on the main branch .
  • Sets up tracking :
    Sets up tracking information for the branch , so you can use git pull and git push without specifying the remote branch.
What is .env file ?

A .env file are used in web development to store environment variable and sensitive information such as

  • API keys
  • Database credentials
  • Secret tokens

What is node-modules ?

A node-module is a directory in Node.js that contains :

Purpose
  • Installed dependencies:
    When you run npm install or yarn install , the dependencies specified in package.json are downloaded and stored in the node_modules directory .
  • Package storage :
    The directory holds the actual code for each dependency , allowing your project to use them.

What is does Readme.MD file do ?

A readme.md file is a Markdown-formatted text file that provides information about a project , repository , or directory .
